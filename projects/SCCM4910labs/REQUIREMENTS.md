# Calculator Requirements

1. Must add two numbers and display the result.
2. Must subtract one number from another and display the result.
3. Must multiply two numbers and display the result.
4. Must divide one number by a non-zero number and display the result.
5. Must display a single result for each valid calculation.

The calculator is complete when all five requirements above work from the command line and each displayed result matches the expected result for its inputs.

## Examples

- Example 1: input `2 + 3` → expected result `5`.
- Example 2: input `10 / 2` → expected result `5` (division by a non-zero number).

These examples help judge whether a test checks a requirement because each pairs a concrete input with its exact expected output, so a test passes only if it runs that input and compares the actual displayed result with the expected value.
